# بدمینتون چرخشی

اپ فارسی برای قرعه‌کشی منصفانه و چرخشی بازیکنان بدمینتون (یک‌نفره یا دونفره، یک یا چند زمین)، ثبت امتیاز، اضافه کردن بازیکن دیررسیده و رنکینگ.

## نصب روی گوشی
- **آیفون (Safari):** لینک را باز کن ← Share ← **Add to Home Screen**
- **سامسونگ / اندروید (Chrome):** لینک را باز کن ← منو ⋮ ← **Add to Home screen** یا **Install app**
