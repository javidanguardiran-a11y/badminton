# والیبال چرخشی

اپ فارسی برای قرعه‌کشی منصفانه و چرخشی تیم‌های والیبال در هر ست، ثبت امتیاز و رنکینگ.

## نصب روی گوشی
- **آیفون (Safari):** لینک را باز کن ← دکمه‌ی Share ← **Add to Home Screen**
- **سامسونگ / اندروید (Chrome یا Samsung Internet):** لینک را باز کن ← منو ⋮ ← **Add to Home screen** یا **Install app**

بعد از نصب، اپ بدون اینترنت هم کار می‌کند. اطلاعات بازی روی همان گوشی ذخیره می‌شود.
